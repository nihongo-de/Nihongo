# Fragewörter & こそあど

Japanisch hat ein erstaunlich **regelmäßiges Zeigesystem**: Vier Silben – <span lang="ja">こ・そ・あ・ど</span> – plus eine Endung ergeben „dies“, „das“, „jenes“ und das passende Fragewort. Wer das System einmal verstanden hat, lernt 28 Wörter auf einen Schlag.

## こそあど – das Zeigesystem {#kosoado}

Entscheidend ist nicht die Entfernung allein, sondern **wem** etwas nahe ist:

<div class="info-grid narrow">
  <div class="info-card"><span class="info-card__big" lang="ja">こ</span><span class="info-card__label">ko · hier</span><span class="info-card__text">nah bei <strong>mir</strong> (Sprecher)</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">そ</span><span class="info-card__label">so · da</span><span class="info-card__text">nah bei <strong>dir</strong> (Zuhörer)</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">あ</span><span class="info-card__label">a · dort</span><span class="info-card__text">weit weg von <strong>uns beiden</strong></span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">ど</span><span class="info-card__label">do · welch-?</span><span class="info-card__text">die <strong>Frage</strong> danach</span></div>
</div>

| Endung – Bedeutung | こ | そ | あ | ど |
| --- | --- | --- | --- | --- |
| **〜れ** dies, das, jenes, welches? (steht allein) | <span lang="ja">これ</span> | <span lang="ja">それ</span> | <span lang="ja">あれ</span> | <span lang="ja">どれ</span> |
| **〜の** dieses …, welches …? (+ Nomen) | <span lang="ja">この</span> | <span lang="ja">その</span> | <span lang="ja">あの</span> | <span lang="ja">どの</span> |
| **〜こ** hier, da, dort, wo? | <span lang="ja">ここ</span> | <span lang="ja">そこ</span> | <span lang="ja">あそこ</span> | <span lang="ja">どこ</span> |
| **〜ちら** Richtung, höflich für Ort und Person | <span lang="ja">こちら</span> | <span lang="ja">そちら</span> | <span lang="ja">あちら</span> | <span lang="ja">どちら</span> |
| **〜っち** dasselbe, locker | <span lang="ja">こっち</span> | <span lang="ja">そっち</span> | <span lang="ja">あっち</span> | <span lang="ja">どっち</span> |
| **〜んな** so ein …, was für ein …? (+ Nomen) | <span lang="ja">こんな</span> | <span lang="ja">そんな</span> | <span lang="ja">あんな</span> | <span lang="ja">どんな</span> |
| **〜う** so, auf diese Weise, wie? | <span lang="ja">こう</span> | <span lang="ja">そう</span> | <span lang="ja">ああ</span> | <span lang="ja">どう</span> |

<Ex jp="{これ}は何[なん]ですか。" ro="kore wa nan desu ka." de="Was ist das (hier bei mir)?" />
<Ex jp="{それ}は辞書[じしょ]です。" ro="sore wa jisho desu." de="Das (bei dir) ist ein Wörterbuch." />
<Ex jp="{あの}人[ひと]は誰[だれ]ですか。" ro="ano hito wa dare desu ka." de="Wer ist die Person dort?" />
<Ex jp="トイレは{どこ}ですか。" ro="toire wa doko desu ka." de="Wo ist die Toilette?" />
<Ex jp="{こちら}は田中[たなか]さんです。" ro="kochira wa Tanaka-san desu." de="Das ist Herr Tanaka. – höfliches Vorstellen" />

::: warning これ oder この?
<span lang="ja">これ・それ・あれ・どれ</span> stehen **allein**, <span lang="ja">この・その・あの・どの</span> brauchen **immer ein Nomen** dahinter.
<span lang="ja">**これ**は私の本です。</span> – Das ist mein Buch. · <span lang="ja">**この**本は私のです。</span> – Dieses Buch ist meins.
Falsch: ~~<span lang="ja">このは</span>~~, ~~<span lang="ja">これ本</span>~~.
:::

::: tip Zwei kleine Unregelmäßigkeiten
- Der Ort heißt <span lang="ja">**あそこ**</span>, nicht ~~<span lang="ja">あこ</span>~~.
- Die Art-und-Weise-Reihe heißt <span lang="ja">こう・そう・**ああ**・どう</span>. Am häufigsten hörst du <span lang="ja">そう</span>: <span lang="ja">そうですね</span> – „Stimmt“, <span lang="ja">そうですか</span> – „Ach so“.
:::

::: info そ und あ im Gespräch
Auch Dinge, die nur **erwähnt** werden, bekommen ein Zeigewort: Hat es gerade dein Gegenüber erwähnt, nimmst du <span lang="ja">そ</span> (<span lang="ja">その話</span> – diese Geschichte, von der du sprichst). Kennt ihr es **beide** von früher, nimmst du <span lang="ja">あ</span> (<span lang="ja">あの店、よかったね</span> – der Laden damals war gut, oder?).
:::

## Die Fragewörter {#fragewoerter}

| Fragewort | Lesung | Bedeutung | Beispiel |
| --- | --- | --- | --- |
| <span lang="ja">何</span> | nani / nan | was | <span lang="ja">何を食べますか。</span> |
| <span lang="ja">誰</span> | dare | wer | <span lang="ja">誰が来ましたか。</span> |
| <span lang="ja">どこ</span> | doko | wo, wohin | <span lang="ja">どこへ行きますか。</span> |
| <span lang="ja">いつ</span> | itsu | wann | <span lang="ja">いつ帰りますか。</span> |
| <span lang="ja">どう</span> | dō | wie (Zustand, Meinung) | <span lang="ja">日本はどうでしたか。</span> |
| <span lang="ja">どうして・なぜ・なんで</span> | dōshite · naze · nande | warum | <span lang="ja">どうして来ませんでしたか。</span> |
| <span lang="ja">いくら</span> | ikura | wie viel (Preis) | <span lang="ja">これはいくらですか。</span> |
| <span lang="ja">いくつ</span> | ikutsu | wie viele (Stück), wie alt | <span lang="ja">りんごはいくつありますか。</span> |
| <span lang="ja">どれ</span> | dore | welches (von mehreren) | <span lang="ja">どれがいいですか。</span> |
| <span lang="ja">どの</span> + Nomen | dono | welches … | <span lang="ja">どの電車に乗りますか。</span> |
| <span lang="ja">どんな</span> + Nomen | donna | was für ein … | <span lang="ja">どんな映画が好きですか。</span> |
| <span lang="ja">どのくらい・どれくらい</span> | dono kurai | wie lange, wie viel | <span lang="ja">どのくらいかかりますか。</span> |
| <span lang="ja">何時</span> | nanji | wie viel Uhr | <span lang="ja">今、何時ですか。</span> |
| <span lang="ja">何人</span> | nannin | wie viele Personen | <span lang="ja">家族は何人ですか。</span> |

<Ex jp="日本[にほん]は{どう}でしたか。" ro="nihon wa dō deshita ka." de="Wie war Japan?" />
<Ex jp="{どんな}映画[えいが]が好[す]きですか。" ro="donna eiga ga suki desu ka." de="Was für Filme magst du?" />
<Ex jp="駅[えき]まで{どのくらい}かかりますか。" ro="eki made dono kurai kakarimasu ka." de="Wie lange braucht man bis zum Bahnhof?" />
<Ex jp="{どうして}日本語[にほんご]を勉強[べんきょう]していますか。" ro="dōshite nihongo o benkyō shite imasu ka." de="Warum lernst du Japanisch?" />

::: tip なに oder なん?
<span lang="ja">何</span> wird **なん** gelesen vor Lauten mit **t, d, n** und vor Zählwörtern – sonst **なに**:
<span lang="ja">**なん**ですか・**なん**の本・**なん**時・**なん**人</span> · <span lang="ja">**なに**を・**なに**が・**なに**色</span>
:::

::: warning 何人 hat zwei Bedeutungen
<span lang="ja">**なんにん**ですか</span> – Wie viele Personen? · <span lang="ja">**なにじん**ですか</span> – Welche Nationalität?
:::

### Höfliche Varianten

Gegenüber Fremden, Kunden oder Vorgesetzten klingen diese Formen freundlicher:

<div class="info-grid">
  <div class="info-card"><span class="info-card__big" lang="ja">どなた</span><span class="info-card__text">statt <span lang="ja">誰</span> – wer</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">どちら</span><span class="info-card__text">statt <span lang="ja">どこ</span> – wo; auch: welches von beiden</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">いかが</span><span class="info-card__text">statt <span lang="ja">どう</span> – wie; beim Anbieten</span></div>
</div>

<Ex jp="コーヒーは{いかが}ですか。" ro="kōhī wa ikaga desu ka." de="Wie wäre es mit einem Kaffee?" />
<Ex jp="お国[くに]は{どちら}ですか。" ro="okuni wa dochira desu ka." de="Woher kommen Sie?" />

## Wo das Fragewort steht {#position}

Das Fragewort steht **genau dort, wo später die Antwort steht**. Die Wortstellung ändert sich nicht, am Ende kommt nur <span lang="ja">か</span>.

<div class="compare">
  <div class="compare__col">
    <div class="compare__head"><span class="compare__kana" lang="ja">？</span><span class="compare__title">Frage</span></div>
    <Ex jp="明日[あした]{どこ}へ行[い]きますか。" de="Wohin gehst du morgen?" />
  </div>
  <div class="compare__col">
    <div class="compare__head"><span class="compare__kana" lang="ja">！</span><span class="compare__title">Antwort</span></div>
    <Ex jp="明日[あした]{京都[きょうと]}へ行[い]きます。" de="Morgen fahre ich nach Kyōto." />
  </div>
</div>

Die **Partikel** bleiben dabei an ihrem Platz – sie verraten, wonach gefragt wird:

<div class="info-grid wide">
  <div class="info-card"><span class="info-card__big" lang="ja">誰と</span><span class="info-card__text">mit wem</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">誰の</span><span class="info-card__text">wessen</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">どこで</span><span class="info-card__text">wo (Handlung)</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">どこから</span><span class="info-card__text">woher</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">いつから・いつまで</span><span class="info-card__text">seit/ab wann · bis wann</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">何で</span><span class="info-card__text"><span lang="ja">なにで</span> womit · <span lang="ja">なんで</span> warum (locker)</span></div>
</div>

::: warning Fragewort als Subjekt → が, nie は
<span lang="ja">は</span> markiert Bekanntes – ein Fragewort ist aber gerade das Unbekannte. Deshalb:
<span lang="ja">誰**が**来ましたか。</span> – Wer ist gekommen? Auch die Antwort nimmt <span lang="ja">が</span>: <span lang="ja">田中さん**が**来ました。</span>
Mehr dazu unter [は vs. が](./partikel-vergleiche#wa-ga).
:::

## Fragewort + か, も, でも {#ka-mo-demo}

Hängst du an ein Fragewort eine Partikel, entstehen Wörter für „etwas“, „nichts“ und „alles“:

| Fragewort | + か → irgend- | + も (+ Verneinung) → kein- | + でも → egal, jede- |
| --- | --- | --- | --- |
| <span lang="ja">何</span> was | <span lang="ja">何か</span> etwas | <span lang="ja">何も〜ない</span> nichts | <span lang="ja">何でも</span> alles, egal was |
| <span lang="ja">誰</span> wer | <span lang="ja">誰か</span> jemand | <span lang="ja">誰も〜ない</span> niemand | <span lang="ja">誰でも</span> jeder |
| <span lang="ja">どこ</span> wo | <span lang="ja">どこか</span> irgendwo | <span lang="ja">どこにも〜ない</span> nirgendwo | <span lang="ja">どこでも</span> überall |
| <span lang="ja">いつ</span> wann | <span lang="ja">いつか</span> irgendwann | – | <span lang="ja">いつでも</span> jederzeit |
| <span lang="ja">どれ</span> welches | <span lang="ja">どれか</span> irgendeins | <span lang="ja">どれも〜ない</span> keins | <span lang="ja">どれでも</span> egal welches |

<Ex jp="{何[なに]か}飲[の]みますか。" ro="nanika nomimasu ka." de="Trinkst du etwas?" />
<Ex jp="{何[なに]も}食[た]べませんでした。" ro="nani mo tabemasen deshita." de="Ich habe nichts gegessen." />
<Ex jp="{誰[だれ]か}いますか。" ro="dareka imasu ka." de="Ist da jemand?" />
<Ex jp="日曜日[にちようび]は{どこにも}行[い]きませんでした。" ro="nichiyōbi wa doko ni mo ikimasen deshita." de="Am Sonntag bin ich nirgendwo hingegangen." />
<Ex jp="{何[なん]でも}いいです。" ro="nan demo ii desu." de="Egal was, alles ist gut." />
<Ex jp="{いつでも}来[き]てください。" ro="itsu demo kite kudasai." de="Komm jederzeit vorbei." />

::: tip Wohin mit den Partikeln?
- <span lang="ja">が</span> und <span lang="ja">を</span> **fallen weg**: <span lang="ja">何**か**食べました</span>, <span lang="ja">誰**も**来ません</span> – nicht ~~<span lang="ja">何もを</span>~~.
- Andere Partikel stehen **vor** <span lang="ja">も</span>: <span lang="ja">どこ**に**も</span>, <span lang="ja">誰**と**も</span> (mit niemandem), <span lang="ja">誰**に**も</span> (niemandem).
:::

::: warning いつも heißt „immer“
<span lang="ja">いつも</span> ist die große Ausnahme in der も-Spalte: Es bedeutet **immer** und steht meist im bejahten Satz. „Nie“ heißt <span lang="ja">一度も〜ない</span> (kein einziges Mal) oder <span lang="ja">全然〜ない</span>.
Auch <span lang="ja">どれも</span> ist bejaht möglich: <span lang="ja">どれもおいしい</span> – alle sind lecker.
:::

::: info Ja/Nein-Frage oder Inhaltsfrage?
<span lang="ja">**何か**食べましたか。</span> – Hast du *etwas* gegessen? → <span lang="ja">はい、パンを食べました。</span>
<span lang="ja">**何を**食べましたか。</span> – *Was* hast du gegessen? → <span lang="ja">パンを食べました。</span>
Mit <span lang="ja">か</span> ist es eine Ja/Nein-Frage, mit dem nackten Fragewort eine Inhaltsfrage.
:::

## Schnelltest

::: details Was gehört in die Lücke? (Lösungen aufklappen)
1. <span lang="ja">（　）は何ですか。</span> – Frage nach einem Ding in der Hand deines Gegenübers → **それ**
2. <span lang="ja">（　）人は誰ですか。</span> – Person weit weg → **あの** (+ Nomen)
3. <span lang="ja">誰（　）来ましたか。</span> → **が** – Fragewort als Subjekt
4. <span lang="ja">「これは（　）ですか。」「三千円です。」</span> → **いくら**
5. <span lang="ja">昨日はどこ（　）行きませんでした。</span> → **にも** – nirgendwohin
6. <span lang="ja">「何（　）食べましたか。」「はい、パンを食べました。」</span> → **か** – Ja/Nein-Frage
7. <span lang="ja">「何人ですか。」「ドイツ人です。」</span> – Lesung von 何人? → **なにじん**
8. <span lang="ja">（　）でもいいです。</span> – „Egal welches (von diesen)“ → **どれ**
:::

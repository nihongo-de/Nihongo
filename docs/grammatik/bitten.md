# Bitten, Wünsche & Vorschläge

Um etwas bitten, sagen, was du willst, jemanden einladen oder Hilfe anbieten: Für all das reichen auf N5-Niveau eine Handvoll Endungen.

## Um etwas bitten {#bitten}

### Dinge: 〜をください

Willst du etwas **haben**, hängst du <span lang="ja">をください</span> oder das etwas weichere <span lang="ja">をお願いします</span> an:

<Ex jp="水[みず]{をください}。" ro="mizu o kudasai." de="Wasser, bitte." />
<Ex jp="コーヒーを二[ふた]つ{お願[ねが]いします}。" ro="kōhī o futatsu onegai shimasu." de="Zwei Kaffee, bitte." />

### Handlungen: 〜てください

Soll jemand etwas **tun**, nimmst du die [て-Form](./verben#te-form) + <span lang="ja">ください</span>:

<Ex jp="ちょっと待[ま]{ってください}。" ro="chotto matte kudasai." de="Warte bitte kurz." />
<Ex jp="もう一度[いちど]言[い]{ってください}。" ro="mō ichido itte kudasai." de="Sag das bitte noch einmal." />
<Ex jp="ここに名前[なまえ]を書[か]{いてください}。" ro="koko ni namae o kaite kudasai." de="Bitte schreiben Sie hier Ihren Namen hin." />

Soll jemand etwas **nicht** tun, nimmst du die ない-Form + <span lang="ja">でください</span> (mehr unter [Verneinung](./verneinung#naide)):

<Ex jp="ここでタバコを吸[す]{わないでください}。" ro="koko de tabako o suwanaide kudasai." de="Bitte rauchen Sie hier nicht." />

::: tip Wie höflich darf es sein?
| Form | Wirkung |
| --- | --- |
| <span lang="ja">待って。</span> | locker, unter Freunden |
| <span lang="ja">待ってください。</span> | höflich, aber klar eine Aufforderung – auch für Anweisungen |
| <span lang="ja">待ってくださいませんか。</span> | fragend, deutlich weicher |
| <span lang="ja">待っていただけませんか。</span> | sehr höflich – gegenüber Vorgesetzten und Kunden |

<span lang="ja">〜てください</span> klingt gegenüber Vorgesetzten schnell wie eine Anweisung. Dort ist die Frageform besser.
:::

## Wünsche: 〜たい und ほしい {#wuensche}

<div class="compare">
  <div class="compare__col">
    <div class="compare__head"><span class="compare__kana" lang="ja">〜たい</span><span class="compare__title">etwas tun wollen</span></div>
    <p>ます-Stamm + <span lang="ja">たい</span>: <span lang="ja">行きます → 行きたい</span></p>
    <Ex jp="日本[にほん]へ行[い]き{たい}です。" de="Ich möchte nach Japan fahren." />
  </div>
  <div class="compare__col">
    <div class="compare__head"><span class="compare__kana" lang="ja">ほしい</span><span class="compare__title">etwas haben wollen</span></div>
    <p>Nomen + <span lang="ja">が</span> + <span lang="ja">ほしい</span></p>
    <Ex jp="新[あたら]しいパソコン{がほしい}です。" de="Ich hätte gern einen neuen Computer." />
  </div>
</div>

Beide konjugieren wie **い-Adjektive**:

| | <span lang="ja">〜たい</span> | <span lang="ja">ほしい</span> |
| --- | --- | --- |
| **Gegenwart** | <span lang="ja">食べたい</span> | <span lang="ja">ほしい</span> |
| **Verneinung** | <span lang="ja">食べたくない</span> | <span lang="ja">ほしくない</span> |
| **Vergangenheit** | <span lang="ja">食べたかった</span> | <span lang="ja">ほしかった</span> |
| **Verg. verneint** | <span lang="ja">食べたくなかった</span> | <span lang="ja">ほしくなかった</span> |

<Ex jp="何[なに]が食[た]べ{たい}ですか。" ro="nani ga tabetai desu ka." de="Was möchtest du essen?" />
<Ex jp="今日[きょう]は何[なに]もし{たくない}です。" ro="kyō wa nani mo shitakunai desu." de="Heute möchte ich gar nichts machen." />
<Ex jp="子[こ]どものとき、犬[いぬ]{がほしかった}です。" ro="kodomo no toki, inu ga hoshikatta desu." de="Als Kind wollte ich (unbedingt) einen Hund." />

::: tip を oder が bei 〜たい?
Beides ist richtig: <span lang="ja">水**を**飲みたい</span> und <span lang="ja">水**が**飲みたい</span>. Mit <span lang="ja">が</span> klingt der Wunsch etwas stärker auf das Ding gerichtet. Bei <span lang="ja">ほしい</span> steht dagegen immer <span lang="ja">が</span>.
:::

::: warning Nur für dich selbst
<span lang="ja">〜たい</span> und <span lang="ja">ほしい</span> beschreiben **eigene** Gefühle – in Fragen auch die des Gegenübers. Über Dritte sagt man <span lang="ja">〜たがっている</span> (N4): <span lang="ja">弟は犬をほし**がっています**。</span> – Mein Bruder will einen Hund.
Und: Vorgesetzte fragt man nicht <span lang="ja">コーヒーを飲みたいですか</span>, sondern bietet an: <span lang="ja">コーヒーは**いかがですか**。</span>
:::

## Vorschläge & Einladungen {#vorschlaege}

<div class="info-grid">
  <div class="info-card"><span class="info-card__big" lang="ja">〜ましょう</span><span class="info-card__label">Lass uns …!</span><span class="info-card__text">Vorschlag, dem der andere wohl zustimmt</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">〜ませんか</span><span class="info-card__label">Wollen wir nicht …?</span><span class="info-card__text">Einladung – lässt Raum für ein Nein</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">〜ましょうか</span><span class="info-card__label">Soll ich / Sollen wir …?</span><span class="info-card__text">Hilfe anbieten oder gemeinsam planen</span></div>
</div>

<Ex jp="そろそろ帰[かえ]り{ましょう}。" ro="sorosoro kaerimashō." de="Lass uns langsam nach Hause gehen." />
<Ex jp="週末[しゅうまつ]、一緒[いっしょ]に映画[えいが]を見[み]に行[い]き{ませんか}。" ro="shūmatsu, issho ni eiga o mi ni ikimasen ka." de="Wollen wir am Wochenende zusammen ins Kino gehen?" />
<Ex jp="窓[まど]を開[あ]け{ましょうか}。" ro="mado o akemashō ka." de="Soll ich das Fenster öffnen? – Angebot" />
<Ex jp="何時[なんじ]に会[あ]い{ましょうか}。" ro="nanji ni aimashō ka." de="Um wie viel Uhr sollen wir uns treffen? – gemeinsam planen" />

::: tip Absagen mit ちょっと…
Ein direktes „Nein“ klingt im Japanischen hart. Üblich ist <span lang="ja">ちょっと…</span> („etwas …“) mit offenem Ende – jeder versteht, dass es nicht geht. Wer mag, schiebt einen Grund oder ein <span lang="ja">また今度</span> („ein andermal“) nach.
:::

::: info Warum ませんか höflicher ist als ましょう
<span lang="ja">〜ましょう</span> setzt die Zustimmung schon voraus. <span lang="ja">〜ませんか</span> fragt – verneint und damit zurückhaltend – ob der andere Lust hat. Für eine **Einladung** ist <span lang="ja">〜ませんか</span> deshalb die bessere Wahl; <span lang="ja">〜ましょう</span> passt, wenn ihr euch schon einig seid.
:::

## Deutsch → Japanisch {#uebersicht}

| Deutsch | Japanisch | Beispiel |
| --- | --- | --- |
| X, bitte (Ding) | <span lang="ja">Xをください · Xをお願いします</span> | <span lang="ja">水をください</span> |
| Tu bitte … | <span lang="ja">〜てください</span> | <span lang="ja">見てください</span> |
| Tu bitte nicht … | <span lang="ja">〜ないでください</span> | <span lang="ja">見ないでください</span> |
| Ich möchte … (tun) | <span lang="ja">〜たいです</span> | <span lang="ja">見たいです</span> |
| Ich möchte X (haben) | <span lang="ja">Xがほしいです</span> | <span lang="ja">時間がほしいです</span> |
| Lass uns … | <span lang="ja">〜ましょう</span> | <span lang="ja">見ましょう</span> |
| Wollen wir nicht …? | <span lang="ja">〜ませんか</span> | <span lang="ja">見ませんか</span> |
| Soll ich …? | <span lang="ja">〜ましょうか</span> | <span lang="ja">見ましょうか</span> |

## Schnelltest

::: details Was sagst du? (Lösungen aufklappen)
1. Im Café: „Einen Tee, bitte.“ → **<span lang="ja">お茶をください。</span>** / **<span lang="ja">お茶をお願いします。</span>**
2. „Bitte sprich langsam.“ (<span lang="ja">ゆっくり話す</span>) → **<span lang="ja">ゆっくり話してください。</span>**
3. „Bitte vergiss es nicht.“ (<span lang="ja">忘れる</span>) → **<span lang="ja">忘れないでください。</span>**
4. „Ich möchte Sushi essen.“ → **<span lang="ja">すしが（を）食べたいです。</span>**
5. „Ich wollte kein neues Auto.“ → **<span lang="ja">新しい車はほしくなかったです。</span>**
6. Du lädst eine Kollegin zum Mittagessen ein. → **<span lang="ja">一緒に昼ご飯を食べませんか。</span>**
7. Jemand trägt schwere Taschen – du bietest Hilfe an. → **<span lang="ja">持ちましょうか。</span>**
8. Du musst eine Einladung höflich ablehnen. → **<span lang="ja">すみません、ちょっと…。</span>**
:::

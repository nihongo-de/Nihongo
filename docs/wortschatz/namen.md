# Deutsche Namen in Katakana

Ausländische Namen werden auf Japanisch in **Katakana** geschrieben. Übertragen wird nach dem **Klang**, nicht nach der Schreibung. *Müller* wird also nicht Buchstabe für Buchstabe übertragen, sondern so, wie man es spricht: <span lang="ja">ミュラー</span> (*myurā*).

<Ex jp="{アンナ・ミュラー}です。ドイツから来[き]ました。" ro="anna myurā desu. doitsu kara kimashita." de="Ich bin Anna Müller. Ich komme aus Deutschland." />

::: tip Vorname zuerst, getrennt mit ・
Westliche Namen behalten ihre Reihenfolge: **Vorname, dann Nachname**. Getrennt werden sie durch den Mittelpunkt <span lang="ja">・</span>, zum Beispiel <span lang="ja">トーマス・マン</span>. Beim Vorstellen reicht meist der Nachname: <span lang="ja">ミュラーです。</span>
:::

## Die wichtigsten Regeln {#regeln}

Japanisch hat fast nur offene Silben (Konsonant + Vokal). Alles, was nicht in dieses Muster passt, wird angepasst. Die allgemeinen Regeln für Lehnwörter stehen unter [Katakana → Wie Fremdwörter japanisch werden](../schrift/katakana#wie-fremdworter-japanisch-werden). Für deutsche Laute gilt zusätzlich:

### Vokale {#vokale}

| Deutsch | Katakana | Beispiel |
| --- | --- | --- |
| langer Vokal (*ie*, *ah*, *ee* …) | **ー** | Peter → <span lang="ja">ペ**ー**タ**ー**</span> · Lena → <span lang="ja">レ**ー**ナ</span> |
| Endung *-er* | **アー** | Becker → <span lang="ja">ベッカ**ー**</span> · Wagner → <span lang="ja">ワーグナ**ー**</span> |
| *ä*, *ö* | **エ**-Reihe | Köln → <span lang="ja">**ケ**ルン</span> · Schröder → <span lang="ja">シュ**レー**ダー</span> |
| *ü* | kleines **ュ** (am Anfang **ユ**) | Müller → <span lang="ja">**ミュ**ラー</span> · Jürgen → <span lang="ja">**ユ**ルゲン</span> |
| *ei*, *ai* | **アイ** | Schneider → <span lang="ja">シュ**ナイ**ダー</span> · Meyer → <span lang="ja">**マイ**ヤー</span> |
| *eu*, *äu* | **オイ** | Neumann → <span lang="ja">**ノイ**マン</span> |
| *au* | **アウ** | Paul → <span lang="ja">**パウ**ル</span> · Bauer → <span lang="ja">**バウ**アー</span> |

### Konsonanten {#konsonanten}

| Deutsch | Katakana | Beispiel |
| --- | --- | --- |
| *sch* | **シュ** (vor *i*: **シ**) | Schulz → <span lang="ja">**シュ**ルツ</span> · Fischer → <span lang="ja">フィッ**シャ**ー</span> |
| *st-*, *sp-* am Anfang | **シュト**, **シュプ** | Stefan → <span lang="ja">**シュテ**ファン</span> |
| *ch* nach *a*, *o*, *u* | **ハ**, **ホ** (meist mit ッ) | Bach → <span lang="ja">バッ**ハ**</span> · Koch → <span lang="ja">コッ**ホ**</span> |
| *ch* nach *e*, *i*, *ü*, Konsonant | **ヒ** | Richter → <span lang="ja">リ**ヒ**ター</span> · Michael → <span lang="ja">ミ**ヒャ**エル</span> |
| *-ig* am Ende | **イヒ** | Ludwig → <span lang="ja">ルートヴィ**ヒ**</span> |
| *s* vor Vokal | **ザ**-Reihe | Sabine → <span lang="ja">**ザ**ビーネ</span> · Sophie → <span lang="ja">**ゾ**フィー</span> |
| *z*, *tz* | **ツ** (**ツァ**, **ツィ**, **ツェ** …) | Zimmermann → <span lang="ja">**ツィ**マーマン</span> |
| *w* | **ヴ** oder **ワ**-Reihe | Wolf → <span lang="ja">**ヴォ**ルフ</span> · Wagner → <span lang="ja">**ワ**ーグナー</span> |
| *v* | **フ**-Reihe | Volker → <span lang="ja">**フォ**ルカー</span> |
| *j* | **ヤ**-Reihe | Jonas → <span lang="ja">**ヨ**ナス</span> · Julia → <span lang="ja">**ユ**リア</span> |
| *l* und *r* | **ラ**-Reihe | Laura → <span lang="ja">**ラ**ウ**ラ**</span> |
| Konsonant ohne Vokal | **ウ**-Reihe, nach *t*/*d*: **ト**/**ド** | Bernd → <span lang="ja">ベル**ント**</span> · Hamburg → <span lang="ja">ハンブル**ク**</span> |
| Doppelkonsonant nach kurzem Vokal | kleines **ッ** | Otto → <span lang="ja">オ**ッ**トー</span> · Becker → <span lang="ja">ベ**ッ**カー</span> |
| *mm*, *nn* | **ン** + Konsonant | Anna → <span lang="ja">ア**ン**ナ</span> · Hannah → <span lang="ja">ハ**ン**ナ</span> |
| *ti*, *di*, *fa*, *fi* … | Sonderkombinationen | Tim → <span lang="ja">**ティ**ム</span> · Felix → <span lang="ja">**フェ**リックス</span> |

Die Sonderkombinationen wie <span lang="ja">ティ・ファ・ヴォ・ツィ</span> findest du unter [Kana-Kombinationen](../schrift/kombinationen#katakana-erweiterungen).

::: warning Es gibt oft mehrere richtige Schreibungen
Katakana-Namen sind nicht genormt. *Weber* kann <span lang="ja">ヴェーバー</span> oder <span lang="ja">ウェーバー</span> sein, *Felix* auch <span lang="ja">フェーリクス</span>. Bekannte Personen haben eine feste Schreibung. Für deinen eigenen Namen wählst du die Variante, die deiner Aussprache am nächsten kommt, und bleibst dann dabei.
:::

::: tip Deutsch oder Englisch ausgesprochen?
*Michael* wird deutsch zu <span lang="ja">ミヒャエル</span>, englisch zu <span lang="ja">マイケル</span>. Entscheidend ist, wie **du** deinen Namen aussprichst. Japaner kennen die englische Form oft besser. Mit der deutschen Form klingt dein Name aber so, wie er eigentlich klingt.
:::

## So findest du deinen Namen {#anleitung}

1. **Sprich deinen Namen laut** und langsam. Achte auf lange Vokale und darauf, welche Silbe betont ist.
2. **Zerlege ihn in Silben** aus Konsonant + Vokal: *Mül-ler* → *myu-rā*.
3. **Wende die Regeln an**: *-er* → <span lang="ja">アー</span>, Doppelkonsonant → <span lang="ja">ッ</span>, Konsonant ohne Vokal → <span lang="ja">ウ</span>-Reihe.
4. **Vergleiche** mit bekannten Namen. Die japanische Wikipedia zeigt, wie berühmte Namensvettern geschrieben werden.
5. **Frag eine Muttersprachlerin oder einen Muttersprachler**, ob es natürlich klingt.

::: tip Auf Japanisch üben
Schreib deinen Namen auf ein [Kana-Schreibblatt](../uebungen/druckvorlagen). Wähle dafür bei „Katakana“ genau die Zeichen deines Namens aus.
:::

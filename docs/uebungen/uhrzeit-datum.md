# Uhrzeit- und Datum-Quiz

Du siehst eine Uhrzeit oder ein Datum, z. B. <span lang="ja">4時</span> oder <span lang="ja">20日</span>, und tippst die **Lesung** ein. Du kannst in Rōmaji tippen (*yoji*, *hatsuka*), die Eingabe wird gleich in Hiragana umgewandelt.

Wähle oben, was du üben willst: Stunden (<span lang="ja">時</span>), Minuten (<span lang="ja">分</span>), Monate (<span lang="ja">月</span>) oder Tage im Datum (<span lang="ja">日</span>). Für die **Tage 1–10** gibt es eigene Lesungen. Wähle nur „1–10“, wenn du sie zuerst sicher lernen willst.

<FormTrainer deck="uhrzeit-datum" />

::: tip Die wichtigsten Sonderlesungen
| | 4 | 7 | 9 |
| --- | --- | --- | --- |
| Uhr (<span lang="ja">時</span>) | <span lang="ja">**よ**じ</span> | <span lang="ja">**しち**じ</span> | <span lang="ja">**く**じ</span> |
| Monat (<span lang="ja">月</span>) | <span lang="ja">**し**がつ</span> | <span lang="ja">**しち**がつ</span> | <span lang="ja">**く**がつ</span> |
| Minuten (<span lang="ja">分</span>) | <span lang="ja">よん**ぷ**ん</span> | <span lang="ja">なな**ふ**ん</span> | <span lang="ja">きゅう**ふ**ん</span> |

Bei den Minuten entscheidet die **letzte Ziffer**: 1, 6, 8 und 0 → <span lang="ja">っぷん</span>, 3 und 4 → <span lang="ja">ぷん</span>, 2, 5, 7 und 9 → <span lang="ja">ふん</span>. Also <span lang="ja">にじゅう**いっぷん**</span> (21), aber <span lang="ja">にじゅう**ごふん**</span> (25).
:::

::: warning Die Tage im Datum
<span lang="ja">ついたち・ふつか・みっか・よっか・いつか・むいか・なのか・ようか・ここのか・とおか</span> (1.–10.), dazu <span lang="ja">じゅう**よっか**</span> (14.), <span lang="ja">**はつか**</span> (20.) und <span lang="ja">にじゅう**よっか**</span> (24.). Alle anderen Tage: Zahl + <span lang="ja">にち</span>, mit <span lang="ja">しち</span> für 7 und <span lang="ja">く</span> für 9: <span lang="ja">じゅうしちにち</span>, <span lang="ja">じゅうくにち</span>.
:::

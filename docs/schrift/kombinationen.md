# Kana-Kombinationen & Sonderzeichen

Mit den 46 Grundzeichen allein kommst du nicht weit. Erst durch diese **sechs Mechanismen**
entsteht der volle Lautbestand des Japanischen.

## Dakuten ゛ und Handakuten ゜ {#dakuten}

Die zwei Striche <span lang="ja">゛</span> machen den Konsonanten **stimmhaft**. Den Kreis <span lang="ja">゜</span> gibt es nur in der h-Reihe – er macht daraus ein **p**.

<div class="info-grid">
  <div class="info-card"><span class="info-card__big" lang="ja">か → が</span><span class="info-card__text">k → <strong>g</strong></span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">さ → ざ</span><span class="info-card__text">s → <strong>z</strong> (stimmhaftes s wie in <em>Sonne</em>)</span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">た → だ</span><span class="info-card__text">t → <strong>d</strong></span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">は → ば</span><span class="info-card__text">h → <strong>b</strong></span></div>
  <div class="info-card"><span class="info-card__big" lang="ja">は → ぱ</span><span class="info-card__text">h → <strong>p</strong> (Handakuten)</span></div>
</div>

::: warning じ/ぢ und ず/づ
<span lang="ja">じ</span> und <span lang="ja">ぢ</span> klingen beide **ji**, <span lang="ja">ず</span> und <span lang="ja">づ</span> beide **zu**.
Im Normalfall schreibst du <span lang="ja">じ</span> und <span lang="ja">ず</span>. <span lang="ja">ぢ／づ</span> erscheinen nur, wenn ein <span lang="ja">ち／つ</span> stimmhaft wird:
<span lang="ja">はな + ち → はな**ぢ**</span> (Nasenbluten), <span lang="ja">つ**づ**く</span> (fortsetzen).
:::

## Yōon – verschmolzene Silben {#yoon}

Ein Zeichen der **i-Spalte** (<span lang="ja">き、し、ち …</span>) plus ein **kleines** <span lang="ja">ゃ ゅ ょ</span> ergibt **eine** Silbe.
Das kleine Zeichen ist etwa halb so groß und sitzt unten links.

<KanaChart script="hiragana" set="yoon" />

::: danger Groß oder klein – ein riesiger Unterschied

Mit kleinem <span lang="ja">ょ</span> verschmelzen *bi* und *yo* zu einer Mora – mit großem <span lang="ja">よ</span> sind es zwei.
:::

## Sokuon – das kleine っ {#sokuon}

Ein kleines <span lang="ja">っ</span> (Katakana: <span lang="ja">ッ</span>) **verdoppelt den folgenden Konsonanten**.
Gesprochen wird es als kurze Pause – genau **eine Mora** lang –, bevor der nächste Laut „explodiert“.

<div class="demo-row">
<MoraSplit kana="きて" ro="kite" de="komm!" />
<MoraSplit kana="きって" ro="kitte" de="Briefmarke" />
</div>

<div class="demo-row">
<MoraSplit kana="さか" ro="saka" de="Hang" />
<MoraSplit kana="さっか" ro="sakka" de="Schriftsteller" />
</div>

::: tip Rōmaji-Regel
In Umschrift wird der Folgekonsonant verdoppelt: <span lang="ja">がっこう</span> → *gakkō*, <span lang="ja">ざっし</span> → *zasshi*.
Vor *ch* wird ein *t* eingefügt: <span lang="ja">マッチ</span> → *matchi*.
:::

## Langvokale {#langvokale}

Ein langer Vokal dauert **zwei Moren**. Wer ihn verkürzt, sagt oft ein ganz anderes Wort.

### Schreibregeln in Hiragana

| Vokal | Verlängert durch | Beispiel |
| --- | --- | --- |
| a | <span lang="ja">あ</span> | <span lang="ja">おか**あ**さん</span> – okāsan (Mutter) |
| i | <span lang="ja">い</span> | <span lang="ja">おに**い**さん</span> – onīsan (älterer Bruder) |
| u | <span lang="ja">う</span> | <span lang="ja">く**う**き</span> – kūki (Luft) |
| e | meist <span lang="ja">い</span>, selten <span lang="ja">え</span> | <span lang="ja">せんせ**い**</span> – sensē (Lehrer), <span lang="ja">おね**え**さん</span> – onēsan |
| o | meist <span lang="ja">う</span>, selten <span lang="ja">お</span> | <span lang="ja">がっこ**う**</span> – gakkō (Schule), <span lang="ja">お**お**きい</span> – ōkii (groß) |

::: info Gesprochen wie geschrieben?
<span lang="ja">えい</span> und <span lang="ja">おう</span> werden in normaler Sprache als langes **ē** und **ō** ausgesprochen – nicht als „ei“ oder „ou“.
:::

In Katakana nutzt du einfach den Strich <span lang="ja">ー</span>: <span lang="ja">ケーキ、スーパー</span>.

## Das silbische ん {#n}

<span lang="ja">ん</span> ist das einzige Zeichen ohne Vokal. Es zählt als **eigene Mora** und passt seinen Klang dem Folgelaut an:

<div class="info-grid">
  <div class="info-card"><span class="info-card__big">[m]</span><span class="info-card__label">vor m, b, p</span><span class="info-card__text"><span lang="ja">さんぽ</span> sampo (Spaziergang), <span lang="ja">しんぶん</span> shimbun (Zeitung)</span></div>
  <div class="info-card"><span class="info-card__big">[n]</span><span class="info-card__label">vor n, t, d, r, z</span><span class="info-card__text"><span lang="ja">おんな</span> onna (Frau), <span lang="ja">ほんだな</span> hondana (Bücherregal)</span></div>
  <div class="info-card"><span class="info-card__big">[ŋ]</span><span class="info-card__label">vor k, g</span><span class="info-card__text">wie „ng“ in <em>Bank</em>: <span lang="ja">りんご</span> ringo (Apfel)</span></div>
  <div class="info-card"><span class="info-card__big">[ɴ]</span><span class="info-card__label">am Wortende</span><span class="info-card__text">Nasal hinten im Rachen, Zunge berührt nichts: <span lang="ja">ほん</span> hon (Buch)</span></div>
</div>

::: warning ん vor Vokalen
Folgt ein Vokal oder y, bleibt <span lang="ja">ん</span> eine eigene Mora. In Rōmaji setzt man einen Apostroph:
<span lang="ja">きんえん</span> *kin'en* (Rauchverbot, 4 Moren) ≠ <span lang="ja">きねん</span> *kinen* (Gedenken, 3 Moren).
:::

## Wiederholungszeichen 々

Das Zeichen <span lang="ja">々</span> wiederholt das vorherige Kanji. Oft wird der zweite Teil dabei stimmhaft (*Rendaku*):

<Ex jp="人々[ひとびと]" ro="hitobito" de="die Leute" />
<Ex jp="時々[ときどき]" ro="tokidoki" de="manchmal" />

## Spickzettel

::: tip Alles auf einen Blick
- <span lang="ja">゛</span> → stimmhaft (k→g, s→z, t→d, h→b) · <span lang="ja">゜</span> → h→p
- **i-Spalte + kleines** <span lang="ja">ゃゅょ</span> → eine Mora (<span lang="ja">きゃ</span> = kya)
- **Kleines** <span lang="ja">っ</span> → Pause + Doppelkonsonant, eine Mora
- **Langvokal** → zwei Moren; in Katakana immer <span lang="ja">ー</span>
- <span lang="ja">ん</span> → eigene Mora, klingt wie n / m / ng
:::

Alle Zeichen und Kombinationen abfragen kannst du im [Kana-Quiz](../uebungen/kana).

# Katakana <span lang="ja">カタカナ</span>

Katakana hat **dieselben Laute** wie Hiragana, nur in eckiger Form. Wenn du Hiragana kannst,
lernst du hier also nur neue Zeichen – keine neuen Laute.

## Der Langvokalstrich ー

In Katakana werden lange Vokale fast immer mit <span lang="ja">ー</span> geschrieben. Er verlängert den
vorherigen Vokal um **eine Mora**. In senkrechter Schrift steht er ebenfalls senkrecht.

## Verwechslungsgefahr: シ ツ ソ ン

Das berüchtigtste Quartett. Der Trick liegt in **Position der Punkte** und **Strichrichtung**:

    <span class="info-card__label">tsu</span>

  <div class="info-card">

    <span class="info-card__label">n</span>
    <span class="info-card__text">Wie <span lang="ja">シ</span> mit nur einem Punkt: Strich geht <strong>nach oben</strong>.</span>
  </div>
  <div class="info-card">
    <span class="info-card__big" lang="ja">ソ</span>
    <span class="info-card__label">so</span>
    <span class="info-card__text">Wie <span lang="ja">ツ</span> mit nur einem Punkt: Strich geht <strong>nach unten</strong>.</span>

::: tip Eselsbrücke
<span lang="ja">シ</span> und <span lang="ja">ン</span>: Punkte links, der lange Strich **steigt auf** wie eine Rakete.
<span lang="ja">ツ</span> und <span lang="ja">ソ</span>: Punkte oben, der lange Strich **fällt herab** wie Regen.
:::

## Wie Fremdwörter japanisch werden

Japanisch kennt (außer <span lang="ja">ン</span>) keine Konsonanten ohne Vokal. Deshalb werden Fremdwörter angepasst:

| Regel | Beispiel |
| --- | --- |
| Nach den meisten Konsonanten kommt ein **u** | *Christmas* → <span lang="ja">クリスマス</span> *kurisumasu* |
| Nach **t** und **d** kommt ein **o** | *test* → <span lang="ja">テスト</span> *tesuto* |
| Nach **ch** und **j** kommt ein **i** | *orange* → <span lang="ja">オレンジ</span> *orenji* |
| Lange Vokale und Endungen wie *-er* → **ー** | *computer* → <span lang="ja">コンピューター</span> *konpyūtā* |
| Kurzer betonter Vokal → kleines **ッ** | *cup* → <span lang="ja">カップ</span> *kappu* |
| **l** und **r** → r-Reihe | *lemon* → <span lang="ja">レモン</span> *remon* |
| **v** → meist b-Reihe | *violin* → <span lang="ja">バイオリン</span> *baiorin* |

Die Sonderzeichen für Laute wie *fa*, *ti* oder *she* findest du unter [Kana-Kombinationen](./kombinationen#katakana-erweiterungen).

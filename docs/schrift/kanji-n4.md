# Die N4-Kanji

Mit diesen 167 Kanji kommst du zusammen mit den [80 N5-Kanji](./kanji-n5) auf rund 250 Zeichen – den Grundstock für **JLPT N4**.
Wie bei N5 gibt es keine offizielle Liste; diese hier folgt den gängigen Lernlisten und enthält keine Zeichen, die schon bei N5 vorkommen.

::: tip So liest du die Karten
<span lang="ja">音</span> = **On-Lesung** (Katakana), <span lang="ja">訓</span> = **Kun-Lesung** (Hiragana, Endungen in Klammern).
Ein „–“ heißt: Diese Lesung ist für Lernende auf diesem Niveau nicht relevant.

Tippe auf ein Kanji, um die **Strichfolge** als Animation zu sehen und das Zeichen selbst nachzuzeichnen.
:::
